# Meta Interview Question Bank

This page lists 59 questions that are commonly reported for the Meta software engineer loop: 31 coding, 15 system design, and 13 behavioral. Each coding problem links to its worked lesson where one is published. Treat the list as practice material, because interviewers change details and add follow-up questions.

### More reported problems

These nine problems appear in the DesignGurus.io list of top Meta coding questions. Their solutions are part of [Grokking the Meta Coding Interview](https://www.designgurus.io/course/grokking-meta-coding-interview?utm_source=github&utm_medium=repo&utm_campaign=meta-interview-guide&utm_content=question-bank).

| # | Problem | Main idea |
|---|---|---|
| 23 | Island Perimeter | Count the land edges that touch water |
| 24 | Move Zeroes | Two pointers, in place |
| 25 | Missing Ranges | One pass over a sorted array |
| 26 | Rank Transform of an Array | Sort and map values to ranks |
| 27 | Palindrome Permutation | Count characters with odd frequency |
| 28 | Basic Calculator II | Stack with operator precedence |
| 29 | Dot Product of Two Sparse Vectors | Store only the non-zero entries |
| 30 | Making a Large Island | Label islands, then test each water cell |
| 31 | Longest Increasing Path in a Matrix | Depth-first search with memoization |

Memoization stores the result of a function call so that the same call is not computed twice.
